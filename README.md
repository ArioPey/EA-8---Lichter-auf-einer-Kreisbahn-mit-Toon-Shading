# Lichter auf einer Kreisbahn mit Toon Shading

WebGL-Szene mit zwei kreisenden Lichtern (Taste L) und schaltbarem Toon-Shader (Taste T).
Reine statische Seite ohne Build-Schritt: `index.html`, `style.css`, `main.js`.

Veröffentlichung mit GitHub Pages: Repository > Settings > Pages > Branch `main`, Ordner `/ (root)`.
